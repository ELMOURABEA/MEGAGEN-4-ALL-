## 📦 What's New in v1.2.0

### 1. Monetization System
Complete subscription tier management:

**Free Tier:**
- 10 queries per day
- 5 research operations per day
- Shallow research only

**Pro Tier ($9.99/month):**
- Unlimited queries and research
- All research depths
- Up to 10 concurrent tasks

**Full Energy Tier ($29.99/month):**
- Everything in Pro
- Up to 20 concurrent tasks
- Priority support

### 2. Advertising Integration
Google AdMob integration:
- Banner ads (configurable placement)
- Interstitial ads
- Rewarded ads with bonuses
- Partnership management
- Ad rental slots

**Configured AdMob IDs:**
- App: `ca-app-pub-8167320193401713~7894343051`
- Banner: `ca-app-pub-8167320193401713/5228651260`

### 3. GitHub Action Support
Use MEGAGENT in your workflows:
```yaml
- uses: ELMOURABEA/MEGAGENT@v1.2.0
  with:
    mode: 'query'
    prompt: 'Your query here'
```

### 4. New APIs
- `get_subscription_tiers()` - View all tiers
- `get_tier_info()` - Check current tier and usage
- `show_banner_ad()` - Display banner ads
- `show_rewarded_ad()` - Show rewarded ads

### 5. Enhanced Testing
- 11 new tests (total: 39)
- Monetization test coverage
- Advertising test coverage
- 100% pass rate maintained

## 🚀 Publishing Instructions

### Quick Start
1. **Merge to Main**
   ```bash
   git checkout main
   git merge copilot/release-update-version-<version>
   ```

2. **Create Tag**
   ```bash
   git tag -a v1.2.0 -m "Release v1.2.0"
   git push origin v1.2.0
   ```

3. **Create GitHub Release**
   - Go to Releases → Draft new release
   - Tag: v1.2.0
   - Title: "MEGAGENT v1.2.0 - Monetization & GitHub Marketplace"
   - Description: Copy from `RELEASE_NOTES_v1.2.0.md`
   - Publish

4. **Publish to Marketplace**
   - Follow steps in `PUBLISHING_GUIDE.md`
   - Select categories: Automation, Continuous Integration
   - Add tags: ai, automation, copilot, gemini, chatgpt, grok
   - Publish

### Detailed Guide
See `PUBLISHING_GUIDE.md` for complete step-by-step instructions.
